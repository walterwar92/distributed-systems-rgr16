## Расчётное задание — вариант 16

Стационарное распределение температуры в цилиндре радиуса a и высоты h с теплоизолированными торцами; на боковой поверхности T = 0 при 0 < z < c и T = T₀ при c ≤ z < h.

Этапы (5 баллов за каждый при сдаче в срок, минус 0,5 балла за неделю просрочки):

1. Математическая постановка задачи по словесному описанию.
2. Функция Грина и аналитическое решение — со всеми выкладками и итоговой формулой.
3. Численное решение методом конечных разностей: шаблон, явная или неявная схема, метод решения СЛАУ. **Метод программируется вручную, готовые решатели запрещены.**
4. Сравнение аналитического и численного решений, анализ зависимости от параметров. Необязательно: сверка с готовым ПО.
5. Защита отчёта.

Отчёт: титульный лист, содержание, постановка задачи, математическая модель, аналитическое решение, численное решение (графики), анализ, выводы, список литературы; оформление по ГОСТ. Итоговый отчёт загружается в https://dl.spbstu.ru/mod/assign/view.php?id=225834 до **22.12.2026 00:00**.

**Защита проходит без компьютера и телефона:** студент должен сам связно изложить отчёт и объяснить любую формулу, символ, алгоритм и вывод. Поэтому каждое решение сопровождать объяснением «почему так», а в `defense/` поддерживать материалы для подготовки.
